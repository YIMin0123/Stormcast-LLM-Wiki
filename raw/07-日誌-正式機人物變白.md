# 正式機人物變全白（Caddy CSP 擋掉 blob:）

- 狀態：已上線（2026-11-17 已用 IAP 放到正式機 Caddy 並 reload，正式網址人物貼圖恢復）
- 日期：2026-11-17
- 作者：Claude Sonnet 5.5
- 提交：見 git log（標題「Caddy CSP 補 blob:」）
- 會動的檔案：deploy/Caddyfile、docs/工程架構手冊.md

## 現象
正式版（https://35-229-248-193.sslip.io/）大廳與遊戲裡的人物（女版、男版都一樣）貼圖消失，整個人變白灰色；本機 localhost 正常。

## 原因
`2026-11-17-正式機管理入口加固.md` 加了 `Content-Security-Policy: connect-src 'self' wss://…`。人物 glb 的貼圖是內嵌的，GLTFLoader 用 `blob:` 網址 fetch 它，`connect-src` 沒放行 `blob:`，貼圖就載不進來，材質沒有 map 變成純白。本機沒有那個標頭所以沒事。在正式網頁的主控台 `fetch(URL.createObjectURL(new Blob(['x'])))` 會失敗，就是這個。Three.js 載貼圖失敗不丟例外，前端也就沒有任何錯誤能抓。

## 修正
`deploy/Caddyfile` 的 `connect-src` 加 `blob: data:`（兩者只能讀瀏覽器自己產生的資料，不會開出去別的主機的路）。手冊那行安全說明補上為什麼不能拿掉。

## 要知道的事
- 這個標頭是 Caddy 送的，**要照 `deploy/README.md`「改 Caddyfile 之後」那段手動放到伺服器並 reload 才會生效**；`push.sh` 不會帶。
- 以後再改 CSP（加 `img-src`、`script-src` 等），要先在正式網址實測人物、音效、海洋貼圖都還在。
