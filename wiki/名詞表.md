# 名詞表：給沒寫過程式的人

| 名詞 | 白話解釋 | 在哪裡出現 |
|---|---|---|
| AI Agent | 能自己讀檔、改程式、跑指令、看結果再決定下一步的 AI | [[多AI協作總覽]] |
| commit（提交） | 把一批改動存成一個有編號的版本，像遊戲存檔點，隨時能回到那裡 | [[交接日誌]] |
| main | 專案的主線版本；這個專案所有 AI 都直接在 main 上改 | [[CLAUDE-md]] |
| 上線 | 把新版放到正式網站給玩家玩 | [[上線流程]] |
| 本機／正式網站 | 本機是自己電腦上跑的測試版；正式網站是玩家連的那個 | [[案例-人物變白]] |
| 主控台 | 瀏覽器裡顯示程式錯誤訊息的地方 | [[案例-白畫面]] |
| CSP | 網站的安全規則，規定網頁只能從哪些地方讀資料 | [[案例-人物變白]] |
| 著色器 | 在顯示卡上算每個像素顏色的小程式 | [[案例-暴風雨誤判]] |
| NaN | Not a Number，「不是數字」：算錯時（例如對負數開次方）得到的結果，會一路傳染 | [[案例-暴風雨誤判]] |
| 伺服器 | 讓所有玩家連進同一個遊戲世界的那台電腦 | [[上線流程]] |
| 跑馬燈 | 遊戲畫面上方捲動的公告，上線前用來倒數提醒玩家 | [[上線流程]] |
| 貼圖 | 貼在 3D 模型表面的圖片，決定它的顏色和花紋；貼圖讀不到，模型就變成一片白 | [[案例-人物變白]] |
| Three.js | 在網頁上畫 3D 畫面的程式庫，Stormcast 用它畫整個遊戲 | [[案例-人物變白]] |
| `blob:` 網址 | 瀏覽器自己在記憶體裡產生的資料網址，不會連到別台電腦 | [[案例-人物變白]] |
| 光暈 | 讓亮的地方往外暈開的畫面效果；一個壞掉的像素也會被它擴散開來 | [[案例-暴風雨誤判]] |
| `git log` | 列出歷次提交紀錄的指令，等於整個專案的歷史 | [[共用記憶]] |
| 審查 | 請別的 AI 看改動、挑錯 | [[審查流程]] |
| Lint | 自動檢查有沒有寫錯、過時的工具 | [[docLint]] |
| docLint | Stormcast 的手冊檢查工具：把手冊裡寫的名字一個個到程式裡找，找不到就是手冊過時了 | [[docLint]] |
| 共用記憶 | 寫成檔案、讓每個 AI 開工前都讀的資料 | [[共用記憶]] |

背景（一般知識）：Lint 原本是檢查程式寫法的工具名稱，後來泛指各種自動檢查。
